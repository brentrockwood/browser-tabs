Browser Tabs — local review

A review surface for this local service, not a second browser or a general agent console. Everything below reads and reviews what the browser and this service's own derived store already hold, with one exception: the "Open a URL in a new tab" section, which can open one tab after you preview and then explicitly approve it.

Owner token

Paste the service's owner pairing token (shown once by npm run service -- start, or re-displayed with npm run service -- show-token). It is kept only in this page's memory for as long as this page stays open — never written to the URL, local storage, session storage, or any log — and is discarded on reload or when you disconnect below.

A separate, more restricted external-agent token (Stage 4) is not sufficient here: it cannot read or decide proposals, delete records, or clear stored data, and this page will not work correctly with it. Use the owner token.

            Proposals
            
  
            
    A proposal is a caller's suggestion, never an applied change. Accepting or rejecting only records your
    decision here; it never itself creates a tag, collection, or queue change.
  
            
  
  
            
  
              

              


              
  
              Open a URL in a new tab
              
  
              
    The only place this page can change the browser (this and the tab-group form below), and only in two steps. Preview records
    exactly which address would be opened and for which browser session; nothing opens yet. Then
    Open on that preview opens it, once, or Reject discards it. A preview can
    be decided only once. If the browser has restarted since the preview, it is refused as stale and nothing
    opens. Only absolute http:// and https:// addresses without a username or password
    are accepted. The tab opens in front, in the browser's current window.
  
              
  
              
    
              
      
      
      
              An absolute http:// or https:// address, up to 2048 characters.
              
    
              
    
  
              
  
              

  
              Create or change a tab group
              
  
              
    The same two steps for tab groups, in Chromium-family browsers only (a browser without tab groups answers
    "unsupported" and nothing changes). Under "Windows, tabs, and groups" above, choose
    Group this tab… to create a new group around that one ungrouped tab, or
    Edit this group… to rename or recolor an existing group. Preview records the
    exact tab or group, the browser session, and its current state; then Apply on that preview
    changes the browser once, only if the tab or group is still exactly as previewed, or Reject
    discards it. Moving other tabs into a group is not offered.
