Owner token

Paste the service's owner pairing token (shown once by npm run service -- start, or re-displayed with npm run service -- show-token). It is kept only in this page's memory for as long as this page stays open — never written to the URL, local storage, session storage, or any log — and is discarded on reload or when you disconnect below.

A separate, more restricted external-agent token (Stage 4) is not sufficient here: it cannot read or decide proposals, delete records, or clear stored data, and this page will not work correctly with it. Use the owner token.
